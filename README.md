# GrowIndiaUP - Corporate Website

GrowIndiaUP is a high-performance corporate landing page designed for a leading building glass manufacturing company. The project highlights the brand's legacy, precision manufacturing processes, and strategic investment plans.

## ✨ Key Features
* **Modern Hero Section:** Engaging visuals with a clear Call-to-Action (CTA).
* **Manufacturing Showcase:** A step-by-step breakdown of the glass production process (Sourcing, Precision, Inspection).
* **Investment Tiers:** Cleanly designed pricing/investment cards ranging from "Star" to "Infinite" plans.
* **Testimonial Section:** Professional feedback display for building trust.
* **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
* **Contact & Lead Gen:** Integrated inquiry form for potential clients and investors.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for better SEO.
* **CSS3:** Custom styling with a professional color palette.
* **Responsive Design:** Mobile-first approach.
